# Day 20｜參數抽取、迭代與條件判斷

> **主題：** 複合問題可拆成多個子問題逐一處理；先驗證抽取到的參數，再決定是否迭代。若輸入沒有可處理項目，走明確的 fallback。

參數抽取是把自然語言轉成欄位值；迭代（iteration）是對清單項目重複執行步驟。Embedding 是文字的數值表示，RAG 利用檢索找相關資料；本例僅手動拆問題，未執行模型或檢索。Fallback 是無可處理項目時採取的後備處理。

## 動手做：拆解問題並迭代

```python
question = "想知道台北到高雄的交通方式，以及高雄有哪些夜市？"
subquestions = [
    "台北到高雄有哪些交通方式？",
    "高雄有哪些夜市？",
]

if not subquestions:
    print("請補充想查詢的問題。")
else:
    for i, item in enumerate(subquestions, start=1):
        print(f"子問題 {i}: {item}")
```

預期輸出：

```text
子問題 1: 台北到高雄有哪些交通方式？
子問題 2: 高雄有哪些夜市？
```

此處用手動列出的子問題示範迭代，並未真的呼叫 LLM 抽取。若由模型抽取參數，應檢查型別、長度與空值；只對通過檢查的項目執行後續工具。控制迭代數量及逾時，也可避免意外的成本和延遲。

## 小練習

將 `subquestions` 改成空清單，確認程式走 fallback。再加入最多處理 3 個子問題的限制，並列印每個項目的序號。
