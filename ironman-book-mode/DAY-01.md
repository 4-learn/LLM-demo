# Day 1｜從問題開始：LLM 應用可以做什麼？

> **定位**：認識這 30 天的路線，先練習把一個需求說清楚，再用 Python 做一個不靠 AI 的文字分類基準。

## 學習目標

- 分辨 AI 與 LLM 應用的範圍。
- 把模糊需求拆成輸入、輸出和檢查方式。
- 執行一個可重現的 Python 基準程式。

## 情境與概念

LLM（大型語言模型）是能處理及生成文字的一類 AI 模型；應用不只聊天，也可協助分類或整理文字。先不要從「用哪個模型」開始，先定義要解決的任務。

例如要整理活動訊息：輸入是一句文字，輸出是「活動」或「其他」，不確定時標記 `unknown`。這個簡單規則程式就是**基準（baseline）**：用來比較之後加入模型是否真的改善結果。

## 動手做：建立基準分類器

以下只用 Python 標準函式庫，使用固定測試資料。複製執行：

```python
cases = [
    ("明天下午有社團講座", "活動"),
    ("記得買牛奶", "其他"),
    ("地點還沒公布", "unknown"),
]

for text, expected in cases:
    if "講座" in text or "活動" in text:
        actual = "活動"
    elif "地點" in text:
        actual = "unknown"
    else:
        actual = "其他"
    print(f"輸入：{text}｜預期：{expected}｜分類：{actual}")
```

**實際輸出（以 Python 執行上述程式）：**

```text
輸入：明天下午有社團講座｜預期：活動｜分類：活動
輸入：記得買牛奶｜預期：其他｜分類：其他
輸入：地點還沒公布｜預期：unknown｜分類：unknown
```

這個小基準只看關鍵字，遇到同義詞或否定句就可能失準；我們先留下它，後續再逐步比較其他方法。

## 練習

新增一筆「週五開會，時間待定」，預期設為 `unknown`。試著調整規則使程式輸出符合預期，並思考：哪些判斷可用固定規則，哪些需要更多脈絡？
