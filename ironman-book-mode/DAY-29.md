# Day 29｜AI 工具選擇：依任務評估，不依品牌追逐

> **定位**：把簡報、論文閱讀、新聞查找與程式協作等任務拆開，練習用來源、隱私、成本和可驗證性評估工具。

## 學習目標
- 將工作需求映射到 AI 工具類別。
- 為生成或搜尋結果設計人工查核步驟。
- 注意資料上傳、帳務、方案與服務變更。

## 概念
不同工具擅長的任務不同：簡報生成協助起草版面、文件問答協助整理指定資料、搜尋型工具彙整網頁、程式助理協助修改程式。它們的輸出仍可能錯誤；不可把摘要當原始證據，也不可讓程式助理未經檢視就執行不理解的命令。

生成式 AI 可依提示產生新內容，搜尋型 AI 會找外部資訊並呈現來源；兩者結果都需查核。此處所說的方案/額度是服務商的計價或使用限制，不把舊文章資訊當成現況。

## 動手做：建立可追溯的查核紀錄

程式只檢查每筆候選事實是否填入來源及人工查核狀態，不判斷內容真假：

```python
claims = [
    {"claim": "活動日期為週五", "source": "https://example.org/event", "checked": True},
    {"claim": "免費提供午餐", "source": "", "checked": False},
]

for item in claims:
    traceable = bool(item["source"].startswith("https://")) and item["checked"]
    status = "待人工查核" if traceable else "缺來源或未核對"
    print(f"{item['claim']}：{status}")
```

**實際輸出：**
```text
活動日期為週五：待人工查核
免費提供午餐：缺來源或未核對
```

網址只是示意，不表示事實已驗證。選一項教師核准的工具（或只看官方產品說明），再填寫評估矩陣：

| 評估面向 | 記錄 |
|---|---|
| 要完成的具體任務 |  |
| 輸入資料是否敏感 |  |
| 輸出如何核對 |  |
| 方案/費用/額度是否已查官方頁面 |  |
| 若服務不可用的替代方式 |  |

工具清單和方案會變動，所以本章不把 2024 年特定產品功能或免費額度當成現況。

## 練習
挑選一份可公開閱讀的短文，使用任一核准工具產生摘要，至少回到原文核對三個事實，記錄一項遺漏或錯誤。不要上傳未獲同意的私人資料。
