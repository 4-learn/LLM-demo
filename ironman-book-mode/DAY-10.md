# Day 10｜本地模型與資料邊界

> **定位**：認識本機推論的資料流與限制，以 Python 模擬本機端點的設定檢查；不安裝或啟動服務。

## 學習目標

- 說明本機模型服務如何透過本機 API 接收請求。
- 用程式檢查端點是否指向 loopback 位址。
- 不把「本地」誤當成完整的隱私保證。

## 概念

Loopback（本機迴送位址）指只連回目前這台裝置的網路介面，常見位址為 `127.0.0.1`；服務若暴露到網路，資料邊界便不同。

本機模型可能減少把提示內容送往雲端供應商的需要，但模型檔、日誌、瀏覽器介面、備份或錯誤設定仍可能暴露資料。下載模型前要看授權與來源，服務部署也需設定存取控制。

## 動手做：檢查本機端點

```python
from urllib.parse import urlparse

endpoint = "http://127.0.0.1:11434"
parsed = urlparse(endpoint)
print("主機：", parsed.hostname)
print("本機端點：", parsed.hostname in {"127.0.0.1", "localhost", "::1"})
```

**實際輸出（以 Python 執行上述程式）：**

```text
主機： 127.0.0.1
本機端點： True
```

這只檢查設定文字，不代表服務真的安全或已啟動。若端點指向公開 IP，程式會印出 `False`；不要在未設認證與網路限制下公開本機模型服務。

## 練習

把 endpoint 改成 `http://example.com:11434`，重新執行並解釋結果。不要嘗試連線或掃描該網域。
