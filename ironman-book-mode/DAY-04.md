# Day 4｜提示詞：把任務說清楚

> **定位**：用固定規格呈現提示詞的角色；以離線 Python 整理任務，不呼叫模型。

## 學習目標

- 說出提示詞是給模型的任務與限制文字。
- 將模糊任務寫成目的、輸入與輸出要求。
- 知道提示詞不能取代程式驗證。

## 概念

提示詞（prompt）是提供給模型的指令與上下文，描述希望模型完成什麼。原文整理 OpenAI 2024 年的提示策略；方法可作為概念參考，但不保證現行模型會有相同表現。

## 動手做：建立可重用的提示模板

```python
template = "任務：{task}\n輸入：{text}\n要求：只列出候選分類；不確定請寫 unknown。"
print(template.format(task="分類活動訊息", text="地點尚未公布"))
```

**實際輸出（以 Python 執行上述程式）：**

```text
任務：分類活動訊息
輸入：地點尚未公布
要求：只列出候選分類；不確定請寫 unknown。
```

這只是產生提示文字，沒有呼叫 LLM。即使模型依格式回答，程式仍須檢查結果是否合法。
